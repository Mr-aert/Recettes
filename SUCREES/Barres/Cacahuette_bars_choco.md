# 

### **Ingrédients** (pour 6-8 personnes) :

- 200gr de beurre de cacahuètes

- 200gr de poudre d’amandes

- Sirop d’agave ou miel

### Options :

- chocolat

### **Préparation** :

1.  Mélanger les ingrédients de base

2.  Mettre dans un tupperware au frigo

3.  Le lendemain, mettre une couche de chocolat (optionnel)

4.  Remettre au frigo
