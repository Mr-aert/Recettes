# Brownie au Brocolis

# Ingrédients

| 1           | Brocolis         |
|:------------|:-----------------|
| 2           | oeufs            |
| 160g        | farine           |
| 1/2         | Feta             |
| (optionnel) | lardons          |
| 25cl        | lait             |
|             | comté rapé       |
| Epices      | sel, poivre, ail |
| 1/2         | sachet levure    |

# Recette

- hacher finement le brocolis cru
- ajouter les autres ingredients et mélanger
- Cuire 30 min à 180
